    \begin{highlights}

        \item Designed a 4-stage pipeline --- OCR preprocessing with OpenCV/Tesseract, LLM field extraction via local Mistral (Ollama), Pydantic v2 schema validation with confidence scoring, and a deterministic rules engine that assigns urgency levels and routes records to safety, field ops, scheduling, or human review
        \item Implemented a confidence-weighted scoring system and human review override UI in Streamlit, enabling operators to correct low-confidence extractions and re-route flagged records in real time
        \item Built an evaluation framework with ground-truth comparison across synthetic test sets, tracking per-field accuracy, routing precision/recall, and accuracy by file type to iterate on prompt and rule quality
    \end{highlights}
